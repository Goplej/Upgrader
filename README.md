# Upgrader

![Icon](src/main/resources/assets/upgrader/icon.png)

Fabric-мод для **Minecraft 1.20.1**: предмет «Улучшатель» открывает меню улучшения — положи свой предмет, выбери тот, который хочешь, заплати материалами.

## Как это работает

1. Скрафти «Улучшатель» (алмаз + книга + железный слиток) или возьми из креатива (вкладка «Инструменты»).
2. Нажми ПКМ — откроется меню.
3. Положи в слот инструмент или броню — справа появятся все доступные варианты улучшения.
4. Нажми на вариант — материалы спишутся из инвентаря, предмет заменится на выбранный.

## Особенности

- **Прыжки через ступени**: можно улучшить деревянный меч сразу до алмазного — стоимость сложится за каждую пропущенную ступень.
- **Сохраняются**: чары, название, «Прочность», покраска, атрибуты, узор брони. Предмет после улучшения полностью цел.
- Цены соответствуют ванильным рецептам (например, меч: 2 материала за ступень).

### Лестницы улучшений

| Тип | Цепочка |
|---|---|
| Инструменты | деревянный → каменный → железный → алмазный → незеритовый |
| Броня | кожаная → кольчужная → железная → алмазная → незеритовая |

Материалы ступеней (инструменты): булыжник → железо → алмаз → незеритовый слиток.

## Сборка

Требуется JDK 17:

```bash
gradle build
```

Готовый jar появится в `build/libs/`. Также jar собирается автоматически через GitHub Actions — смотри вкладку *Actions* репозитория.

## Структура кода

- `UpgraderMod` — регистрация предмета, типа экрана и сетевого приёмника.
- `UpgradeRegistry` — лестницы улучшений и стоимость ступеней.
- `UpgraderScreenHandler` — серверная логика: проверка, списание материалов, замена предмета.
- `client/UpgraderScreen` — отрисовка меню и кнопки улучшений.
